# Software citation and research credit

CITATION.cff describes this software repository only. Guillaume Lauzier consented
to the initial software-author entry on 2026-11-24. No affiliation, ORCID, DOI,
archive URL, paper authorship, or private book metadata is inferred or invented.

Substantial original software design, implementation, or sustained maintenance can
justify software authorship after contributor agreement and maintainer review.
Credit other contributions, such as reviews, tests, documentation, datasets, and
issue reports, in release acknowledgements with the person's preferred public
name and consent. Commit history provides provenance but is not automatically an
authorship list. Resolve credit disputes through the governance decision process.
Software credit does not confer book or paper authorship; each publication has its
own contribution and consent decision.

On an actual release, update `version` and `date-released` in CITATION.cff together
to match the released tag and date, validate the official CFF 1.2.0 schema, and
archive the exact release if approved. Add a DOI/archive URL only after it exists
and resolves to that release. Until then cite a commit SHA and access date; do not
fabricate a release number or publication date. Reviewer verifies metadata and
author consent before release sign-off.
