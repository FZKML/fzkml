# Protocol specifications

`numeric-contract-v1.json` and NUMERIC-CONTRACT.md define the implemented tiny exact
public-input relation. It is not a complete federated security protocol. New
specifications must define version, inputs, witnesses, computation, numeric
encoding, trust model, assumptions, and failures.

M0 version 0.1 specifications cover [deployment](m0/deployment-v0.1.md), the
[standalone relation](m0/relation-v0.1.md), [measurement](m0/measurement-v0.1.md),
[fixtures](m0/fixtures-v0.1.md), [capabilities](m0/capabilities-v0.1.md) and the
[security target/open obligations](m0/security-v0.1.md). These are reviewable
targets, not an implemented or independently reviewed protected protocol.
