# Reproducible experiments

No scientific experiment has been run. New definitions record exact implementation
and specification versions, environment, asset provenance IDs, configuration,
seeds, commands, results, failures, and output artifact hashes. Publish only
approved public artifacts; private/restricted inputs stay outside tracked paths.

The [M0 preregistration](m0/preregistration-v0.1.md) fixes the initial comparison
and identifies unavailable protected arms. `m0/reporting-cases.json` contains
fictional acceptance cases for CI-04, not measured results. The model/assurance
matrix and primary-source replication cards in `m0/` state their current scope
and missing evidence. A source paper's results are never local run evidence.
